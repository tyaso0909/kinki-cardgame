# 禁域 — ぶっ壊れカードゲーム

敵も味方も壊れたコンボを使う、ファンタジー世界のローグライク・カードバトル。
ブラウザだけで遊べます（スマホ・PC 対応、インストール不要）。

## 遊び方

- **オンライン：** GitHub Pages で公開しているページを開くだけ。
- **ローカル：** このリポジトリをダウンロードして `index.html` をブラウザで開く。
  一部ブラウザで動かない場合は、フォルダで `npx serve .` や `python3 -m http.server` を実行して表示してください。

セーブデータはブラウザ（localStorage）に保存されます。

## 特徴

- パックを開けて初期デッキ30枚を組み、3幕のマップを進むローグライク
- 加速・循環・複製・連鎖・時間・終焉の6系統と汎用カード、遺物、禁忌カード
- ループ・連鎖・特殊勝利など、敵もプレイヤーも「壊れた」勝ち方を狙う
- 深度（難易度）0〜10、図鑑・実績・記録、日替わりの祭り
- ドラッグ操作、一斉攻撃、ダーク／ライトテーマ、効果音（Web Audio で合成）

## 構成

ビルド不要の素の JavaScript です。

```
index.html       エントリ
css/             スタイル
js/core, engine  ルールエンジン（DOM 非依存）
js/data          カード・遺物・敵・イベント・テキスト
js/ai            敵AI
js/run           ラン進行（パック・マップ・ショップ・報酬）
js/meta          セーブ・深度・図鑑・実績・記録
js/ui            画面と演出
docs/            仕様書・設計メモ
tests/           Node で動くテスト
```

## テスト

```
node tests/run.js
```
