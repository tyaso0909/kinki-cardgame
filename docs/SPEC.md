# ぶっ壊れカードゲーム 企画書

Nov 5, 2026 · @黒魔導師ゼレフ

## コンセプト

色々なカードゲームの「強すぎて禁止されるような効果」を集めた、NPC戦専用のカードゲーム。プレイヤーも敵も無限ループやワンターンキルを仕掛けてくる、いい意味でのお祭り騒ぎを楽しむ。

| 項目 | 内容 |
| --- | --- |
| 対戦形式 | NPC戦のみ |
| プラットフォーム | デジタル（スマホ・PC） |
| ゲーム形式 | ローグライク（デッキ構築型） |
| 世界観 | ファンタジー全般（ストーリーなし。断片テキストでにおわせる） |
| カードの種類 | モンスター・魔法・紋章・フィールド |

既存ゲームのカードは効果の方向性だけを参考にし、名前と効果はすべてオリジナルで作る。

## 世界観とテキスト

ストーリーはない。世界観はファンタジー全般で、竜もエルフも妖怪も魔導機械も天使も悪魔も、何でもありのごった煮にする。物語は語らず、日記の断片やフレーバーテキストで少しだけにおわせる。

### 方針

- **答えを出さない**：断片を集めても、謎の全体像ははっきりとは分からない。
- **固有名詞は少なめ**：地名や人名はほとんど出さず、「あそこ」「あいつ」でにおわせる。
- **日付と数字で時系列をにおわせる**：日記の「三日目」「四十日目」などで、書き手の変化を感じさせる。
- **ギャグも混ぜる**：お祭りゲームなので、不穏な文章の隣にくだらない落書きがあっていい。
- **属性はもりもり**：系統ごとの属性（炎と竜、水と書庫、雷、時の魔術、幻影、死霊と古の封印）に加えて、和風・西洋・神話・魔導機械など、ファンタジーの要素は何でも混ぜてよい。

### 裏設定（表には出さない）

テキストを書く人だけが知っておく設定。プレイヤーには断片からしか伝わらない。

- 舞台は、あらゆる世界で「強すぎる」と封じられたカードや力が捨てられる場所。属性がごちゃ混ぜなのは、そのため。
- プレイヤーも敵も、そこに流れ着いた力を求めてやってきた挑戦者。
- ボスたちは、かつての挑戦者のなれの果て。「鏡の主」は、前のランのプレイヤー自身かもしれない。

### テキストの置き場所

| 置き場所 | 内容 |
| --- | --- |
| カードのフレーバーテキスト | 一部のカードだけに1〜2行。効果とは関係のない一言 |
| 遺物の説明文 | 持ち主の痕跡がにじむ短い一文 |
| 日記の切れ端 | イベントマスや宝箱で拾い、図鑑に集まる。全30枚ほどで、拾う順番はばらばら |
| 店主のひとこと | ショップに入ったときのセリフ |
| ボスの最期の一言 | 撃破したときに一度だけ出る |
| ロード画面の落書き | 前の挑戦者たちが残した壁の落書き |

### テキスト例

**日記の切れ端**

- 「三日目。拾ったカードを使ったら、竜が二匹出た。頼んだのは一匹だ。」
- 「十二日目。今日の店主は昨日と顔が違う。品ぞろえは同じ。」
- 「四十日目。鏡の向こうの俺が、俺より先に砂時計を使った。」
- 「ここに捨てられたのは、カードじゃなくて」（ここで途切れている）

**フレーバーテキスト**

- 《巡る不死鳥》「死ぬのにも飽きた鳥。」
- 《焚べ火の祭壇》「火は何度でも灯る。灯す者がいる限り。」

**店主のひとこと**

- 「禁忌？ 売るなら買うよ。使うなら止めないよ。」

**ボスの最期の一言**

- ループ職人「……あと一周で、終わったのに。」

**ロード画面の落書き**

- 「ここで無限を見た者、手を挙げろ」（その下に、手の絵がびっしり描かれている）

## 設計の柱

全員がワンキルできると「先にコンボを始めた方が勝つだけ」になるため、壊れカード同士の綱引きを作る。

- **敵のコンボは予告制**：敵が仕掛ける前に兆候を見せ、プレイヤーが止める猶予を作る。
- **妨害も壊れている**：打ち消し、効果の反射、ループの乗っ取りなどを用意する。
- **勝ち筋の多層化**：ライフを高めにし、特殊勝利・山札切れ・ループ勝利も並べる。
- **ループのルール**：ループは回数を宣言してショートカットできる。双方止められない無限ループは、仕掛けた側の勝ち。
- **ループには必ず出口が要る**：出口のカードを潰されると不発になるので、敵の無限ループも止められる。

## デジタルならではの仕組み

紙では処理しきれない壊れ方を、自動処理と演出で快適にする。

- **ループの自動検出**：同じ盤面が繰り返されたら「ループ実行 ×10 / ×100 / ∞」ボタンを出す。∞なら即決着。止める手段がなければ999回で強制終了し、「オーバーフロー」演出を入れる。
- **危険度メーター**：敵の手札にそろったコンボパーツの数でメーターが上がる。満タン直前が妨害のタイミング。
- **連鎖演出**：1ターンに使ったカードが10枚、50枚と増えるたびに、カウンター表示が派手になり、BGMも盛り上がる。

## ラン構成

1回のランは全3幕。各幕の分岐マップを進み、幕の最後でボスと戦う。

- **マップのマス**：通常戦、エリート、ショップ、イベント、休憩
- **報酬**：ゴールド、カード、パック、遺物（常時効果。遺物もぶっ壊れ）。詳しくは「ラン中のデッキ作り」
- **系統の寄せ方**：カード報酬に系統タグを表示し、ショップで系統指定のパックを買えるようにする

### ボスの系統案

| ボス | 得意な戦い方 | 攻略の鍵 |
| --- | --- | --- |
| ループ職人 | 2枚の無限コンボを狙う | パーツを1枚でも潰せば弱体化 |
| ストームの魔術師 | 1ターンに30枚以上使って焼き尽くす | 連鎖が始まる前に止める |
| 時間泥棒 | 追加ターンを連打する | 予約魔法や妨害モンスターで耐える |
| 蒐集者 | 特殊勝利パーツを集める | 時間制限内に倒す |
| 鏡の主 | プレイヤーのデッキをコピーして戦う | 自分のデッキの弱点を突く |

ボスごとに固有フィールドを持たせ、戦闘開始時から展開しておく。

### ボスの出現

各幕のボスは、その幕の候補からランダムに1体選ばれる。ボスはマップの一番上に最初から表示されるので、プレイヤーはボスに合わせてデッキを作っていける。

| 幕 | ボス候補 |
| --- | --- |
| 第1幕 | ループ職人、蒐集者 |
| 第2幕 | ストームの魔術師、時間泥棒 |
| 第3幕 | 鏡の主（最終ボスとして固定） |

- 鏡の主はプレイヤーのデッキを写すボスなので、ランの総決算として第3幕に固定する。
- 今後ボスを増やすときは、各幕の候補に追加していく。第3幕にも、鏡の主の前に戦う候補を足すことを検討する。

## ラン開始：パック開封で初期デッキを作る

固定の初期デッキは使わない。ラン開始時に6回パックを選んで開け、出た30枚がそのまま初期デッキになる。毎回違うデッキで始まり、開封の瞬間からお祭りが始まる。

### 流れ

1. **パックを選ぶ**：8種類のパックからランダムに3種類が並び、1つを選んで開ける。
2. **6回繰り返す**：毎回並ぶパックは変わる。前に開けたパックの中身を見ながら、次のパックを選べる。
3. **出たカードはすべてデッキに入る**：5枚×6パック＝30枚が初期デッキ。選んで抜くことはできない。
4. **事故防止**：5パック目までに出口（勝ち筋）のカードが1枚もないときは、6パック目に出口カードが1枚確定で入る。
5. **初期遺物を選ぶ**：開けたパックの系統を優先して3種が提示され、1つ選ぶ。

### パックの種類（8種類）

| パック | 中身（5枚） | 向いている人 |
| --- | --- | --- |
| 加速パック | 加速系統のコモン3枚＋加速系統のレア以上1枚＋汎用コモン1枚 | 系統を決め打ちしたい |
| 循環パック | 同上（循環系統） | 系統を決め打ちしたい |
| 連鎖パック | 同上（連鎖系統） | 系統を決め打ちしたい |
| 時間パック | 同上（時間系統） | 系統を決め打ちしたい |
| 複製パック | 同上（複製系統） | 系統を決め打ちしたい |
| 終焉パック | 同上（終焉系統） | 系統を決め打ちしたい |
| 混沌パック | 全系統と汎用からランダムに5枚。うち2枚はレア以上が確定 | 一発逆転を狙いたい |
| 妨害パック | 汎用・妨害カード5枚。うち1枚はレア以上 | 敵のコンボを止めたい |

### レア以上の枠の確率

| レアリティ | 確率 |
| --- | --- |
| レア | 85% |
| 伝説 | 14% |
| 禁忌 | 1%（いきなり禁忌が出る「神引き」） |

## ラン中のデッキ作り

デッキは「足す」と「売る」で作っていく。パックのカードはすべてデッキに入るので、強いカードと一緒に不要なカードも増える。「パックで広げて、売却で絞る」のが基本の流れ。

### デッキを変える方法

| 方法 | 場所 | 内容 |
| --- | --- | --- |
| パック開封 | エリート・ボスの報酬、ショップ | 中身の5枚はすべてデッキに入る |
| 単品カード | 通常戦の報酬、ショップ | 通常戦：3枚から1枚選ぶ（スキップ可）。ショップ：ランダムに並ぶ6枚から買う |
| 売却 | ショップ | 1回の来店につき3枚まで。ゴールドを得る |
| 削除 | 休憩マス | 回復の代わりに1枚削除する（ゴールドは得られない） |

### ゴールドの入手

| 入手方法 | 目安 |
| --- | --- |
| 通常戦 | 20〜30G |
| エリート | 50〜70G |
| ボス | 120G |
| カードの売却 | 下の価格表のとおり |

### 価格の目安

| 品目 | 購入 | 売却 |
| --- | --- | --- |
| コモン | 40G | 10G |
| レア | 100G | 30G |
| 伝説 | 250G | 80G |
| 禁忌 | ショップには並ばない | 150G |
| 系統パック | 100G | — |
| 混沌パック | 150G | — |
| 妨害パック | 80G | — |

### ルール

- デッキは最低20枚。これを下回る売却・削除はできない。上限はない。
- 禁忌カードはショップに並ばない。入手方法はボス報酬と、パックの神引き（1%）のみ。

### この仕組みの狙い

- **同じ系統のパックを重ねる**と、コンボパーツがそろいやすい安定型になる。**違う系統を混ぜる**と、系統をまたぐコンボが偶然生まれる。
- **混沌パック**は事故もあるが、伝説や禁忌を引けば最初から壊れたランになる。
- \*\*売却の上限（1回3枚）\*\*があるので、コンボだけの薄いデッキにはすぐにはならない。絞り込みはランを通じて少しずつ進む。
- **禁忌は高く売れる**ので、「使うか、売って資金にするか」の判断が生まれる。
- クリア報酬として、新しいパック（例：伝説が1枚確定する「黄金パック」）を解放していく要素も検討する。

## 戦闘ルール

敵もプレイヤーと同じ仕組み（デッキ・手札・マナ）で戦うため、敵も本物のコンボを決めてくる。

### ターンの流れ

1. **開始**：マナが最大マナまで回復し、1枚引く
2. **メイン**：カードを使う。攻撃もメイン中にいつでもできる
3. **終了**：「ターン終了時」の効果を処理する。手札が6枚を超えていれば6枚に減らす。残ったマナは消える

### 先攻と後攻

- 戦闘開始時にコイントスで決める。演出として毎回コインが回る。
- 先攻は、最初のターンの開始時にカードを引かない。後攻は通常どおり引く。
- どちらも1ターン目の最大マナは1。

### 手札

- **初期手札**：5枚。引き直し（マリガン）はない。
- **手札の上限**：6枚。ただし上限が効くのはターン終了時だけで、ターン中は何枚持っていてもよい。
- **上限を超えたとき**：ターン終了時に手札が6枚を超えていたら、残す6枚を選び、それ以外を捨てる（捨てたカードは墓地へ）。
- ボスや敵も同じルールで戦う。

### ライフとマナ

- **ライフ**：プレイヤーは40前後。ボスは100〜300など桁違いにし、ワンキル級の火力が必要になるようにする。
- **マナ**：そのターンだけ使える量。ターン終了時に消える。
- **最大マナ**：毎ターン開始時に回復する量。1ターン目は1から始まり、毎ターン+1され、上限はない。加速カードでさらに増え、後半ほどインフレする。

## カードの種類

カードはモンスター・魔法・紋章・フィールドの4種類。罠は一旦見送り、妨害は「自分のターンに先手を打つ」形で用意する。

| 種類 | 置き場所と上限 | 特徴 |
| --- | --- | --- |
| モンスター | 場に最大5体 | 攻撃してライフを削る。召喚時・破壊時の効果がコンボの部品になる |
| 魔法 | 使ったら墓地へ | 自分のターンにだけ使える。加速・ドロー・火力の中心 |
| 紋章 | 紋章ゾーンに最大5枚、同名は1枚まで | 基本的に除去できない。エンジン役に絞る |
| フィールド | お互いに共有で1枚だけ | 両者に平等に効く全体ルール。新しく出すと上書き |

### モンスター

- 出したターンは攻撃できない（速攻持ちは例外）。
- 攻撃先は、相手のライフか相手のモンスター。受けたダメージは次のターンも残る。
- **キーワード**：速攻、守護（これがいる間、他は攻撃されない）、召喚時、破壊時、常在（場にいる間ずっと効く）
- **ループの形**：召喚時効果＋手札に戻す、破壊時効果＋蘇生、トークン増殖

### 魔法

- **予約**キーワード：相手の次のターンに効く魔法。罠の代わりの妨害手段。

### 紋章

- 6枚目を置くときは、古い紋章を1枚選んで入れ替える。
- 強すぎる紋章には「〇ターンで消える」寿命を付けて調整する。

### フィールド

- 古いフィールドは上書きされると墓地へ行く。
- 出した側だけ「展開時」効果を得られる。

| フィールド例 | 効果 |
| --- | --- |
| 竜脈の火山 | マナを得るとき、さらに+1 |
| 鏡の湖 | 魔法はすべて2回発動する |
| 静寂の神殿 | 1ターンに使えるカードは5枚まで（コンボを止める） |
| 終わらぬ夜 | ターン終了時、墓地の一番上のカードを手札に戻す |

### 罠なしでの妨害手段

- **予約魔法**：相手の次のターンを制限する
- **手札への干渉**：危険度メーターで見えた敵のコンボパーツを、狙って捨てさせる
- **妨害モンスター**：例「常在：相手は1ターンにカードを10枚までしか使えない」。倒されれば解除される
- **フィールドの上書き**：敵のコンボを支えるフィールドを潰す

## カード系統設計

カードは「6つの系統」と「4つの役割」の組み合わせで設計する。どの系統を拾ってもコンボの形が見えるようにする。

### 4つの役割（全系統に共通）

- **エンジン**：コンボを回し始めるカード
- **燃料**：マナ・手札・墓地などの資源を補うカード
- **出口**：ループや連鎖を勝ちにつなげるカード
- **妨害**：相手のコンボを止めるカード

### 6つの系統

| 系統 | 属性イメージ | 内容 |
| --- | --- | --- |
| 加速 | 炎と竜 | マナ増加、コスト踏み倒し |
| 循環 | 水と書庫 | ドロー、墓地回収、手札入れ替え |
| 連鎖 | 雷 | 使ったカード枚数に応じた効果 |
| 時間 | 時の魔術 | 追加ターン、ターン巻き戻し |
| 複製 | 幻影 | コピー、トークン増殖、効果の重ねがけ |
| 終焉 | 死霊と古の封印 | 特殊勝利、勝利パーツ集め |

### 系統をまたぐ代表コンボ

- **加速×連鎖**：マナを爆増させてカードを大量に使い、連鎖で焼き切る
- **循環×複製**：回収とコピーで無限ループを作る
- **時間×循環**：追加ターンのカードを回収し続けて無限ターンにする
- **複製×終焉**：勝利パーツをコピーして一気にそろえる

### レアリティ

| レアリティ | 割合 | 強さの目安 |
| --- | --- | --- |
| コモン | 50% | 単体でもそこそこ強く、2〜3枚そろうとループの部品になる |
| レア | 30% | 単体で壊れている |
| 伝説 | 15% | コンボの核。2枚でループが完成する |
| 禁忌 | 5% | 主にボス報酬。パックからもごくまれに出る（1%）。ルールそのものを書き換える |

### 枚数の目安

6系統×各25枚＝150枚に、汎用・妨害カード30枚を加えて、合計約180枚。

## イベントマス

マップ上では「？」で表示され、入るまで中身は分からない。ほとんどが「リスクを取れば大きく得る」選択で、ランに波乱を起こすのが役目。日記の切れ端の主な入手先でもある。

### 基本ルール

- 同じイベントは、1回のランで1度しか出ない。
- 選択肢の中には、結果がランダムなものがある。成功・失敗は派手な演出で見せる。
- 日記の切れ端は、イベントでどの選択肢を選んでも、確率で手に入る（基本10%）。
- 一部のイベントは第2幕以降にだけ出る。

- イベントでどの選択肢を選んでも、10%の確率で日記の切れ端が見つかる。
- まだ持っていない切れ端だけが出る。全部そろうと、もう出なくなる。

## 敵AIの共通ルール

通常敵・エリート・ボスのすべてが従う、考え方の土台。目指すのは「本気でコンボを狙ってくるが、ずるはせず、止めるチャンスを必ずくれる」相手。

### 3つの約束

1. **ずるをしない**：AIが見られるのは、プレイヤーが見られる情報と同じ（場・紋章・フィールド・墓地・手札の枚数など）。プレイヤーの手札や山札の中身は、カードや遺物の効果で見たときだけ分かる。
2. **予告なしで決着しない**：ワンキルや無限ループなど、勝負を決めるコンボは、必ず危険度メーターの予告を出したあとのターンに使う。予告を出したターンに決着コンボは撃たない。
3. **止められたら諦めずに組み直す**：パーツを潰されたらメーターが下がり、別の道を探す。

### 毎ターンの考え方（優先順位）

AIは自分のターンに、上から順に判断する。

1. **勝てるなら勝つ**：予告済みで、このターンに勝てるなら決着コンボを使う。
2. **負けを防ぐ**：プレイヤーが次のターンに勝ちそうなら、妨害カードを使う。
3. **コンボを進める**：狙うコンボのパーツを探す・置く・手札にそろえる。
4. **盤面を整える**：攻撃するか、守りのモンスターを残すかを決める。
5. **資源を管理する**：手札が6枚を超えそうなら、使わないカードから先に使うか、捨てる候補を決める。

### 戦い方の型

敵ごとに1つの型を持たせ、同じ優先順位でも性格の違いを出す。

| 型 | 特徴 | 例 |
| --- | --- | --- |
| 速攻型 | 毎ターン攻撃し、早く削り切ろうとする | 火吹きトカゲ、竜の巣の番犬 |
| 組み立て型 | パーツを集めてから、一気にループを回す | ループ職人、永劫の書守 |
| 溜め型 | 数ターン動かずに溜め込み、1ターンで爆発する | ストームの魔術師、雷鳴の楽隊 |
| 妨害型 | プレイヤーの動きを止めることを優先する | 見張りの石像、囁く司書 |
| 特殊勝利型 | ライフより、鍵や呪詛を積むことを優先する | 蒐集者、骨拾いの小鬼 |
| 写し型 | プレイヤーの使ったカードやデッキを真似る | 鏡の主、鏡写しの道化団 |

### 危険度メーターの共通ルール

- 敵ごとに「狙うコンボのパーツ」と、それぞれの重み（合計100%）を決めておく。
- パーツが手札・場・紋章ゾーンにあると、その重みだけメーターが上がる。手札にあるパーツは、名前は見せずにメーターの量だけで伝える。
- 敵のターン終了時にメーターが100%なら、予告を出す。次の敵のターンに決着コンボを使う。
- パーツを潰されてメーターが100%を下回ったら、予告は取り消される。
- 狙うコンボを複数持つ敵は、一番メーターが高いものを表示する。

### 妨害カードの使いどき

AIはプレイヤーの手札が見えないので、見えている情報から判断する。

- プレイヤーがエンジン（紋章や常在効果のモンスター）を出したとき。
- プレイヤーが同じターンに多くのカードを使い始めたとき（連鎖数やループの兆候）。
- プレイヤーの封印ゾーンの鍵や、敵に置かれた呪詛が、勝利ラインに近づいたとき。
- 除去や奪う効果の対象は、「プレイヤーのコンボのエンジン」→「AIのコンボを止めている妨害モンスター」→「攻撃力の一番高いモンスター」の順に選ぶ。

### ループの扱い

- AIは出口のないループは始めない。
- ループはプレイヤーと同じくループ検出でショートカットし、勝つのに必要な回数だけ回す。
- 回している途中で妨害されたら、その時点で止まる。

### その他の判断

- **フィールド**：今のフィールドがプレイヤーのほうに有利なら、上書きを優先する。
- **手札上限**：捨てるときは、狙うコンボのパーツを最後まで残す。
- **攻撃**：守護のモンスターは、プレイヤーの攻撃が怖いうちは攻撃に使わず残す。

### 強さの調整

AIはわざと少しだけ間違える。

| 敵 | 最善でない手を選ぶ確率 |
| --- | --- |
| 通常敵 | 20% |
| エリート | 10% |
| ボス | 0%（ただし予告のルールは必ず守る） |

### 開発のための仕組み

- **コンボ辞書**：カードごとに「組み合わせると強いカード」と「そのコンボの出口」を登録しておく。AIは手札と場をこの辞書と照らし合わせて、狙うコンボを選ぶ。鏡の主は、この辞書でプレイヤーのデッキのコンボを読み取る。
- **テンポ**：AIの長い連鎖やループは、自動で早送りする。プレイヤーは画面をタップすればさらに速くでき、ループはショートカットの結果だけを見せる。

## ボス詳細設計

ボスはプレイヤーと同じルール（初期手札5枚、毎ターン1枚ドロー、マナの仕組みも同じ）で戦う。各ボスは固有フィールド・遺物・専用デッキ30枚を持ち、危険度メーターでコンボの進み具合を見せる。

**ボスのカード構成のルール**

- デッキのテーマ（系統）は、プレイヤーと同じカードプールで組む。
- 切り札になるコンボパーツと、出口（勝ち筋）のカードは、ボス専用のオリジナルカードにする。
- **切り札は奪えない**：ボスを倒しても、切り札のカードは報酬にならない。戦闘中に簒奪の儀などで一時的に奪うことはできる。
- 切り札以外の補助的な専用カードは、撃破報酬としてデッキに加えられる。

**ボス撃破時の禁忌カード**

- ボスを倒すと、禁忌カードの候補から1枚を選んでデッキに加えられる。
- 第1幕のボスは3択、第2幕のボスは4択。先に進むほど選べる幅が広がる。
- すでに持っている禁忌カードは候補に出ない。
- 第3幕の鏡の主はランの最後なので、禁忌カードの報酬はない。
- 禁忌カードは選ばずにスキップしてもよい。

### ボス1：ループ職人

2枚の無限コンボを組み立ててくる、教科書のようなボス。「パーツを1枚潰せば止まる」ことをプレイヤーに教える役割で、第1幕のボス候補。

| 遺物 | 職人の作業台、欠けた歯車 |

2. **組み立て**：祭壇を紋章ゾーンに置き、不死鳥と出口を手札にそろえる。
3. **予告**：危険度メーターが満タンになると「次のターン、無限ループを開始する」と表示する。
4. **起動**：祭壇で不死鳥を回して無限マナを作り、最後の一周で決着を狙う。

**攻略の鍵**

- 不死鳥を**消滅の光**で除外する。墓地や手札に戻らないので、ループが止まる（欠けた歯車で1回は戻るので、2回目が本番）。
- 祭壇は紋章なので普通は消せない。**封印の鎖**なら除去できる。
- 出口を潰す手もある。**手札崩し**や**先読みの賢者**で最後の一周を落とす。
- **零の聖域**や**ループ断ちの鎖**で、ループそのものを止める。
- 一番気持ちいいのは、**簒奪の儀**で不死鳥を戦闘中だけ奪い、工房のフィールドでこちらがループを回すこと。

**撃破時**

- 最期の一言：「……あと一周で、終わったのに。」
- 報酬：120G、ボス遺物（3種から1つ）、禁忌カード（3択から1枚）、補助の専用カード（職人の予備部品）をデッキに加えるかどうか選べる。
- 日記の切れ端（専用）：「歯車の音が止まらない。止め方を書いたメモを、どこかに挟んだはずだ。」

**行動パターン**

1. **溜め**：ドローとマナ加速だけを使い、手札を増やしていく。攻撃はほとんどしない。
2. **予告**：危険度メーターが満タンになると、空に雷雲が集まる演出とともに「次のターン、嵐が来る」と表示する。
3. **嵐**：嵐の指揮者を出してから、無限の坩堝や0コストのカードで手札を一気に使い切り、終曲・万雷や嵐の化身で決着を狙う。
4. **嵐のあと**：手札を使い切っているので、数ターンは無防備になる。ここが反撃のチャンス。

**危険度メーターの上がり方**

| 状況 | 上昇量 |
| --- | --- |
| 手札が上限の6枚ある | +30% |
| 無限の坩堝か嵐の指揮者が手札にある | +30% |
| 出口（終曲・万雷・嵐の化身）が手札にある | +30% |
| 嵐の大精霊が場にいる | +10% |

**発狂（ライフ90以下）**：「嵐の余韻」状態になる。嵐のあと、そのターンの連鎖数の半分が次のターンに持ち越される。無防備な時間が短くなる。

**攻略の鍵**

- **嵐の指揮者を倒す**。嵐の途中でも、破壊すれば連鎖数が0に戻り、嵐が不発になる。
- **溜めの間に手札を崩す**。手札が多いほど**手札崩し**や**先読みの賢者**で出口を落としやすい。
- **静寂の神殿**でフィールドを上書きする。帯電する天空が消え、1ターン5枚までに抑えられる。
- 予告が出たら、**避雷針**や**雷雲の封印**で嵐のターンを弱める。**結界の僧兵**を立てておくのも有効。
- 嵐のターンに**全反転の大鏡**が決まれば、嵐のダメージはすべてボス自身に返る。

3. **予告**：鏡像の写しが手札にそろうと、画面の鏡がゆらぐ演出とともに「次のターン、おまえの前のターンを映す」と表示する。

- **もう一人の挑戦者**は、こちらの最強モンスターを写すだけなので、強いモンスターを出す前に霧払いの風や消滅の光を用意する。

- 報酬：補助の専用カード（ひび割れた手鏡）が図鑑に登録され、次のラン以降のパックから出るようになる。
- 日記の切れ端（専用）：「鏡の中の俺が、先に手を振った。俺はまだ、手を上げていなかった。」

## 難易度とやり込み要素

ストーリーがないぶん、何度もランを回したくなる仕掛けで遊びを長く保つ。軸は「難しくしていく深度」「集める図鑑と解放」「お祭りルールで遊ぶ特別ラン」の3つ。

### 難易度：禁域の深度

クリアすると、次の深度が解放される。深度ごとに条件が1つずつ追加され、前の深度の条件もすべて引き継ぐ。どの深度でも、敵AIの「予告なしで決着しない」約束は変わらない。

| 深度 | 追加される条件 |
| --- | --- |
| 0 | 通常の難易度 |
| 1 | 通常敵のライフ+10% |
| 2 | エリートが各幕で1回多く出る |
| 3 | ショップの価格+10%、売却価格-10% |
| 4 | 初期デッキのパック選択で、並ぶパックが3種類から2種類になる |
| 5 | ボスのライフ+15% |
| 6 | 呪われた遺物を1つ持った状態でランを始める |
| 7 | 通常敵とエリートが、わざと間違える確率が半分になる |
| 8 | エリートが遺物を2つ持つ |
| 9 | ボスの発狂が、ライフ半分ではなく65%で始まる |
| 10 | ボスが遺物をもう1つ持つ。深度10のクリアで「禁域を越えた者」の称号 |

### 図鑑

集める楽しみの中心。達成率に応じて、見た目の報酬が解放される。

| 項目 | 中身 |
| --- | --- |
| カード | 全180枚＋ボスの補助の専用カード。一度手に入れると登録される |
| 遺物 | 全44種 |
| 敵 | 通常敵15種、エリート6種、ボス5体。倒すと登録され、切り札も見られるようになる |
| 日記の切れ端 | 全30枚＋ボスの専用の切れ端。読む順番はばらばらで、並べ替えて読める |

- 達成率に応じて、カードの裏面のデザインや、箔押し（光る加工）のカードの見た目が解放される。
- 日記の切れ端をすべて集めると、ロード画面に新しい落書きが1枚だけ増える。答えは出さず、においを少し強めるだけにする。

### パックの解放

条件を満たすと、初期デッキ作りやショップに新しいパックが加わる。

| パック | 中身 | 解放条件 |
| --- | --- | --- |
| 黄金パック | 5枚のうち1枚は伝説が確定 | 初めてランをクリアする |
| 二重系統パック | 2つの系統から半分ずつ。系統をまたぐコンボが組みやすい | 3つ以上の系統でそれぞれ1回クリアする |
| 禁忌パック | 5枚のうち1枚は禁忌が確定。代わりに呪われた遺物を1つ押し付けられる | 深度5をクリアする |

### 挑戦（実績）

派手なプレイほど報われるように、壊れた勝ち方そのものを目標にする。達成すると称号がもらえる。

| 挑戦 | 称号 |
| --- | --- |
| 1ターンで100ダメージを与える | 百雷 |
| 連鎖数50を達成する | 嵐を呼ぶ者 |
| 無限ループで勝利する | 永久機関 |
| 特殊勝利でボスを倒す | 封印の主 |
| 全反転の大鏡で、ボスの決着コンボを返して勝つ | 鏡返し |
| 鏡の主を、自分の前のターンを映される前に倒す | 映らぬ者 |
| 禁忌カードを3枚持った状態でランをクリアする | 禁忌の蒐集家 |
| 壁の落書きで受け取ったカードを使って勝つ | 託された者 |

### お祭りラン（日替わり・週替わり）

全員が同じ条件で遊ぶ特別なラン。通常のランにはない「お祭りルール」が付く。

- **同じ種**：パックの中身、マップ、敵の出方がすべて全員同じになる。
- **お祭りルールの例**：
  - すべてのカードのコストが0
  - フィールドを2枚まで置ける
  - 禁忌カード1枚を持ってランを始める
  - 敵も味方もライフが2倍、ダメージも2倍
  - パックの中身がすべて混沌パック
- **記録**：クリアまでのターン数、1ターンの最大ダメージ、最大連鎖数を、ほかのプレイヤーと比べられる（対戦はないので、記録の比べ合いだけ）。

### 自分の記録

普段のランでも、プレイヤーごとの最高記録を残しておく。

- 1ターンの最大ダメージ
- 最大連鎖数
- 一番長く回したループ
- 最高クリア深度
- 一番多く使った系統、一番多く使ったカード
