## 2. 前任QAの修正（推定）

1. **`js/engine/loop.js`**：`stateHash` に幻影の攻撃状態（damage/attacksLeft）を追加。同名の幻影を何体も顔面に攻撃させると「ループ検出」が誤爆していた。回帰テスト `tests/engine_edge.test.js`「QA: attacking face with several identical phantoms is not detected as a loop」。

4. **`css/base.css`**：`.screen > .col > *` に `flex-shrink: 0`（縦に長い画面でイベント文やパックが潰れて切れていた）。
5. **`css/run.css`**：パック開封画面の見出しに全体メニューボタン分の余白、パック名の縦書きが2列に折れないよう `nowrap`、マップ最下段が下部ヒントに隠れないよう余白。

## 5. バランス（第1幕・40ラン）

詳細と理由は `docs/DEVIATIONS.md`「QA tuning」。計測は `balance_sim2.js`（seed 1000〜1039、深度0、人間側は `G.AI.takeTurn`（assemble）＋出口許可。括弧内は「余ったマナで安全なカードを使い全員で攻撃する」攻撃的な人間代理）。

調整内容（データのみ・カード文とエンジンは不変）：
- 霧の双子姉妹：消えない残像 → 見習いの火球（全快でも勝率42%・平均被ダメ33/40 の外れ値だった）
- 火吹きトカゲ：焦熱解放 2→1、火の粉の妖精 2→3
- 戦闘勝利後の回復：通常戦・エリート勝利で最大ライフの20%、ボス勝利で全快（`G.Run.POST_BATTLE_HEAL_RATE`）。それまで回復は休憩マスだけで、幕の切り替わりでも回復しなかった。

| 指標 | 調整前 | 調整後 |
| --- | --- | --- |
| 1戦目の勝率 | 58% | 73%（85%） |
| 2戦目 | 45% | 61%（73%） |
| 3戦目 | 40% | 71%（79%） |
| 第1幕ボス到達 | 4/40 | 8/40（11/40） |
| 第1幕クリア | 3/40 | 5/40 |
| 霧の双子姉妹の勝率 | 25% | 77% |
| 全快状態での2〜4戦目の勝率 | 77〜92% | 93〜100% |

注意：人間代理AIはかなり弱い（攻撃してくる小型モンスターと相打ちしない、勝ちの約45%が敵の山札切れ）。実際の人間の数字はこれより良いはず。それでも1戦ごとに15〜25点削られる消耗戦なので、まだ厳しめ。次の候補は「勝利後回復 25%」か「休憩 30%→40%」（`balance_sim2.js` に `POSTHEAL` / `REST` の環境変数あり）。
